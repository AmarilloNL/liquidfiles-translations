# LiquidFiles Translations

Free language files (locales) for [LiquidFiles](https://www.liquidfiles.com/). There are 29 languages with 1,378 strings each, based on LiquidFiles **v4.2.17**.

**🌐 Website with download buttons: https://amarillonl.github.io/liquidfiles-translations/**

**📦 [Download all languages (.zip)](https://github.com/AmarilloNL/liquidfiles-translations/releases/latest/download/liquidfiles-translations.zip)**

## How to install

1. Download a `.yml` file below. Right-click **Download** and choose *Save link as…*, or use the website.
2. In LiquidFiles, go to **Admin → System → Locales** and add it as a new locale.
3. Set the default language in **Admin → Configuration → Settings**, or let users choose it under **Account Settings**. LiquidFiles also picks up the browser language automatically.
