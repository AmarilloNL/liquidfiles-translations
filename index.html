    Install in Three Steps

    Everything happens in the LiquidFiles admin console. No command line needed.

    1. Download

      Download the .yml file for your language, or the zip with all 29.

    2. Upload

      Go to Admin → System → Locales and add the file as a new locale.

    3. Activate

      Set the default in Admin → Configuration → Settings, or let users choose it in Account Settings.

    Frequently Asked Questions

    Which LiquidFiles version do these match?

    They were made from the English strings of LiquidFiles v4.2.17. Other 4.x versions work as well. Any string a file doesn't have is shown in English.

    Do regional browser languages use these files?

    Yes. LiquidFiles falls back from a regional code to the base language, so a browser set to de-AT or fr-BE uses the de or fr file.

    Can I change the wording?

    Yes. After uploading, you can edit any string under Admin → System → Locales. You can also edit the YAML file before uploading it.

    I found a mistake. How do I report it?

    Open an issue or send a pull request on GitHub. Native speakers are very welcome.

    Is this an official LiquidFiles project?

    No. This is an independent community project and isn't affiliated with or endorsed by LiquidFiles.
