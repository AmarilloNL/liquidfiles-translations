    How to install

    1. Download

      Pick a language above and save the .yml file.

    2. Upload

      In LiquidFiles, go to Admin → System → Locales and add the file as a new locale.

    3. Choose

      Set the default in Admin → Configuration → Settings, or let users pick it under Account Settings. The browser language is detected automatically.

    Found a wrong translation? Open an issue or send a pull request. This is a community project and isn't affiliated with LiquidFiles. Strings added in newer LiquidFiles versions will fall back to English.
