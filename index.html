    Installation

    Live in three steps.

    No restart, no command line. Everything happens in the LiquidFiles admin console.

    1. 01

      Download

      Grab a single .yml file above, or the zip with all 29 languages.

    2. 02

      Upload

      Open Admin → System → Locales and add the file as a new locale. Locales apply to every domain on the appliance.

    3. 03

      Activate

      Set a default under Admin → Configuration → Settings, or let users choose in Account Settings. Browser languages are detected automatically.

    FAQ

    Good to know.

    Which LiquidFiles version do these match?

    They were made from the English strings of LiquidFiles v4.2.17. Older and newer 4.x versions work too. Any string a file doesn't have is shown in English.

    Will regional browser languages pick these up?

    Yes. LiquidFiles falls back from a regional code to the base language, so a browser set to de-AT or fr-BE uses the de or fr file. You can add a small regional file on top for the strings that differ.

    Can I change wording to fit my organisation?

    Of course. Once a locale is uploaded you can edit any string under Admin → System → Locales, or edit the YAML before uploading it.

    I found a mistake. How do I report it?

    Open an issue or send a pull request on GitHub. Native speakers are very welcome.

    Is this an official LiquidFiles project?

    No. This is an independent community project and isn't affiliated with or endorsed by LiquidFiles.
